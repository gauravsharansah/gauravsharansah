## `$ ls -la ./projects`

### 🔷 [IOE Gurukul](https://ioegurukul.vercel.app) — *Full-Stack · Solo Build*
> Online exam platform for IOE students — built around the official TU IOE syllabus, with negative marking, AI tutoring, and a real-time classroom.
```
Stack: React 18 + Vite  ·  FastAPI  ·  MongoDB  ·  Oracle Cloud  ·  Vercel  ·  GitHub Actions  ·  TailwindCSS  ·  KaTeX  ·  Groq API
```
- 🧪 **5 exam modes** — Full Mock, Daily Practice, Weekly, Chapter Practice and Old Question tests (IOE-accurate negative marking), with **server-side scoring and autosave**
- 🤖 **Guru** *(Coming soon)* — AI study assistant (Llama 3.3 70B) scoped strictly to IOE subjects
- 💬 **Live Classroom** — SSE-powered real-time discussion room, notifications, and an admin panel for questions, tests, and users
- 📐 **LaTeX rendering** — native math via KaTeX, Word export with OOXML equations
- 🔐 **Secure auth** — JWT, CSRF protection, rate limiting, and single active session enforcement via rotating session tokens
- 🚀 **Load-tested for 300–400 students** on a free-tier Oracle Cloud VM (E2.1.Micro)
- ⚡ **9 DB queries** via `asyncio.gather` for test generation
